# pyGigaSt

自作スペクトラムアナライザ **GigaSt v5** を PC から操作するアプリです。
スペクトラムアナライザ・トラッキングジェネレータ（TG）・信号源（SG）として使えます。RTL-SDR のドングルもスペクトラムアナライザとして使えます。
デスクトップの画面と、ブラウザの画面の両方から、同じ機器を操作できます。

**開発中です。** NF 測定・校正の画面・ウォーターフォールはまだ使えません。

## 必要なもの

- GigaSt v5 本体（USB 接続。FTDI の USB シリアル変換を使います）
- FTDI の仮想 COM ポートドライバ
- Python 3.13

## 環境構築

プロジェクトのフォルダに `venv` を作り、必要なパッケージを入れます。

Windows（コマンドプロンプト・PowerShell のどちらでも。PowerShell では先頭に `.\` を付けて `.\setup.bat`）:

```bat
setup.bat
setup.bat C:\path\to\python.exe
```

Linux / macOS:

```sh
./setup.sh
./setup.sh /path/to/python3
```

- Python を指定しないときは、環境変数 `PYGIGAST_PYTHON`、次に `py -3.13`（Windows）、最後に PATH 上の `python` / `python3` を使います
- `virtualenv` が入っていればそれを、無ければ標準の `venv` を使います
- 作った環境の Python は `venv\Scripts\python.exe`（Linux / macOS は `venv/bin/python`）です。有効化（activate）しなくても使えます

## 旧アプリ（GS5.exe）からの移行

- 旧アプリの校正ファイル（`gigast.txt` や、機器ごとの個別補正データ）はそのまま読み込めます
- 旧アプリの設定ファイルと保存形式には対応しません

## Web 画面（ブラウザから使う）

```sh
venv\Scripts\python.exe -m pygigast --web          # Qt 画面と一緒に開く（この PC のブラウザから http://127.0.0.1:8080/）
venv\Scripts\python.exe -m pygigast serve          # 画面なしで開く
venv\Scripts\python.exe -m pygigast serve --lan    # スマホや別の PC からも使う
```

- 既定はこの PC のブラウザからだけ使えます。スマホや別の PC からも使えるのは、`--lan` を付けて起動したときか、デスクトップの画面のメニュー「設定 → アプリ設定…」の「ブラウザから使う」で「同じネットワークのスマホや PC からも使えるようにする」を選んだときだけです
- スマホや別の PC からも使えるようにすると、接続のしかた（QR コード2つ: 操作できる・見るだけ、URL、6桁の認証番号）を出します。スマホのカメラで QR を読むか、`http://<この PC のアドレス>:8080/` を開いて認証番号を入れます。認証番号は 2 分で無効になります
  - デスクトップの画面: メニュー「設定 → ブラウザから使う: 接続のしかたを表示…」で開き直すと新しい番号を出します。画面の下端の「ブラウザから接続 …」から、つながっている相手の一覧と切断・認証の作り直しができます
  - `serve --lan`: コンソールに URL・QR・認証番号を出します。Enter で新しい認証番号、`r` と Enter で認証を作り直します（覚えていた全部のブラウザが切れます）
- 接続用のリンクと認証番号はアプリを起動するたびに変わります。暗号化（HTTPS）はしていないので、信頼できないネットワークでは使わないでください。インターネットには公開しないでください
- Web 画面からの保存・書き出しはブラウザへダウンロードし、開くファイルはブラウザから送ります（サーバーの PC のフォルダは指定しません）
