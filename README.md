# NamiBench

自作スペクトラムアナライザ **GigaSt v5** を PC から操作するアプリです。設定して、掃引して、マーカーで読む、という計測器と同じ流れで使えます。

| 機器 | 使えるモード |
| --- | --- |
| GigaSt v5 | SA（スペクトラムアナライザ）・TG（伝送特性）・S11（反射）・SG（信号源）・NF（NF 測定） |
| PlutoSDR | SA・TG・S11・SG |
| RTL-SDR のドングル | SA だけ（受信専用） |

デスクトップの画面のほかに、同じ PC やスマートフォンのブラウザからも同じ機器を操作できます。

開発中のため、メニューの「機器 → 自己診断の結果」はまだ使えません。

## 必要なもの

- Windows 10 / 11（Linux・macOS 用の `setup.sh` もありますが、確かめているのは Windows だけです）
- [Python 3.13](https://www.python.org/downloads/)（64 ビット版）
- 機器と、その機器のドライバ
  - **GigaSt v5**: FTDI の USB シリアルのドライバ。Windows は挿すと自動で入ることが多いです。入らないときは FTDI の VCP ドライバを入れます
  - **RTL-SDR**: `rtlsdr.dll`（64 ビット版）と、[Zadig](https://zadig.akeo.ie/) で入れ替えた WinUSB のドライバ
  - **PlutoSDR**: Analog Devices の libiio（v0.26 以降の Windows 64 ビット版）

機器が無くても、シミュレータで画面と操作を試せます。

## インストール

1. Python 3.13 を入れます。
2. このリポジトリを取ってきます。`git clone https://github.com/imenihs/NamiBench.git` か、GitHub の「Code → Download ZIP」で取って展開します。
3. 取ってきたフォルダの `setup.bat` をダブルクリックします。フォルダの中に `venv` を作り、必要なパッケージを入れます。

Python が見つからないと言われたときは、Python の場所を付けて動かします（PowerShell では `.\setup.bat`）。

```bat
setup.bat C:\path\to\python.exe
```

Linux / macOS では `./setup.sh`（Python を指定するときは `./setup.sh /path/to/python3`）を動かします。

## 起動

`run.bat` をダブルクリックします。Linux / macOS では `venv/bin/python -m namibench` を動かします。

起動すると、前回使った機器に自動で繋ぎます。繋げないときは機器の一覧が開くので、使う機器の［接続］を押します。何も挿していなければ［シミュレータで試す］で試せます。別の機器に替えるときは、メニューの「機器 → 機器に接続…」を使います。

## 画面の見方

- **上段**: Center・Span・Start・Stop・RBW・REF・dB/div と、右端の［連続］［単発］［停止］です。TG・S11 では［基準を取る］なども出ます
- **グラフ**: 横にドラッグするとその範囲に拡大します。周波数軸の上でホイールを回すと拡大・縮小します。レベル軸の上でホイールを回すかドラッグすると REF が動きます
- **マーカー表**: グラフの下にあり、マーカーの周波数とレベルを読みます
- **右のタブ**: 「トレース・掃引」「マーカー」「表示」「信号源」の4つです
- **画面の下端**: 接続の状態、出力中かどうか、注意などが出ます

数値の欄には単位を付けて打てます（`1.2G`・`300k`・`1500`）。Enter で決まり、Esc で打つ前の値に戻ります。条件を変えすぎたときは Ctrl+Z で戻せます。

## 測ってみる（SA: 信号を見る）

1. GigaSt の SP 入力に、測る信号を入れます。
2. Center と Span（または Start と Stop）を打ちます。例: Center `433.92M`、Span `2M`。
3. ［連続］（F5）で掃引を始めます。
4. グラフの上で `P` を押すと、マーカーがいちばん高いピークに付きます。`[` `]` で左右の次のピークへ、`←` `→` で1点ずつ（Shift を付けると10点ずつ）動きます。グラフをクリックすればそこにマーカーを置けます。
5. 読み終えたら Ctrl+S で保存し、Ctrl+P で PNG を保存します。

ノイズに埋もれた信号を見るときは、「トレース・掃引」タブでトレースの動作を「平均」や「最大保持」にします。

## 通過特性を測る（TG）

フィルタやアンプの周波数特性を測ります。

1. メニューの「モード → TG（伝送特性）」（Ctrl+2）に切り替えます。
2. 測る範囲を Start・Stop で決めます。
3. 被測定物だけを外し、TG 出力と SP 入力を繋ぎます。ケーブルやアッテネータは測るときと同じものを使います。
4. 上段の［基準を取る］を押します。基準が取れると、グラフが 0 dB 付近の線になります。
5. TG 出力と SP 入力の間に被測定物を入れます。グラフが基準との比（dB）になります。
6. マーカーで損失や帯域を読みます。−3 dB の帯域幅は、「マーカー」タブの機能を「N dB 帯域幅」にして N に 3 を入れると出ます。

基準は取ったときのイメージ除去と RBW のときだけ使えます。GigaSt は USB を抜き挿しすると出力レベルが変わるので、そのあとは基準を取り直してください。

## 反射を測る（S11）

外付けの方向性結合器を使って、リターンロスと SWR を測ります（位相は測れません）。

1. メニューの「モード → S11（反射）」（Ctrl+3）に切り替えます。
2. 結合器の、被測定物を繋ぐ端子にオープンを繋ぎ、上段の［オープンを測る］を押します。
3. オープンを外してショートを繋ぎ、［ショートを測る］を押します。
4. 被測定物を繋ぎます。縦軸はリターンロス・|Γ|・SWR から選べます。

## よく使うキー

| キー | 操作 |
| --- | --- |
| F5 / F6 / F7 | 連続 / 単発 / 停止 |
| Pause | 連続と停止を切り替える |
| Ctrl+1〜5 | モードを SA / TG / S11 / SG / NF に切り替える |
| P | 選んでいるマーカーをピークへ（グラフの上で） |
| `[` / `]` | 次のピーク（左 / 右） |
| ← / → | マーカーを1点動かす（Shift で10点） |
| M | マウスの位置にマーカーを置く |
| Delete | 選んでいるマーカーを消す |
| Ctrl+Z / Ctrl+Y | 条件の変更を戻す / やり直す |
| Ctrl+S / Ctrl+O | 保存 / 開く |
| Ctrl+E | CSV に書き出す |
| Ctrl+P / Ctrl+Shift+C | PNG を保存 / PNG をクリップボードへ |

キーの割り当ては、メニューの「設定 → キー操作…」で変えられます。全部のキーは「ヘルプ → キー操作の一覧」で見られます。

## 保存と書き出し

- **保存（Ctrl+S）**: トレース・マーカー・条件を HDF5（`.h5`）に保存します。h5py・MATLAB・HDFView などで読めます
- **開く（Ctrl+O）**: 保存したファイルを、いまのグラフに重ねて比べられます。グラフへドラッグ&ドロップしても開けます
- **CSV に書き出す（Ctrl+E）**: 表計算ソフトで使う形で書き出します
- **PNG（Ctrl+P）**: グラフ・マーカー表・測定条件を1枚の画像にします
- **記録**: メニューの「ファイル → 記録を開始」で、掃引を続けて記録します。記録したファイルを開くと再生できます
- **プリセット**: よく使う条件に名前を付けて保存し、呼び出します（メニューの「ファイル → プリセット…」）

## ブラウザから使う

この PC のブラウザから使うときは、`--web` を付けて起動し、`http://127.0.0.1:8080/` を開きます。

```bat
run.bat --web
```

スマートフォンや別の PC から使うときは、メニューの「設定 → 設定…」の「ブラウザから使う」で「同じネットワークのスマートフォンや PC からも使う」を入れます。QR コードと認証番号が出るので、スマートフォンのカメラで QR コードを読みます。

- 暗号化（HTTPS）はしていません。信頼できないネットワークでは使わないでください。インターネットには公開しないでください
- 画面なしで動かすときは `run.bat serve`（スマートフォンからも使うなら `run.bat serve --lan`）です。URL・QR コード・認証番号はコンソールに出ます

## RTL-SDR・PlutoSDR を使う準備

### RTL-SDR

1. Zadig で、ドングルのドライバを WinUSB に入れ替えます。
2. `rtlsdr.dll`（64 ビット版）を、アプリのフォルダの `rtlsdr` フォルダに置きます。別の場所に置いたときは、メニューの「設定 → 設定…」の「RTL-SDR」でそのフォルダを選びます。
3. ドングルを挿すと、機器の一覧に出ます。

レベルは「dB（未校正）」で、絶対値（dBm）ではありません。

### PlutoSDR

1. libiio の DLL 一式（`libiio.dll` と、同じフォルダにある DLL）を、アプリのフォルダの `libiio` フォルダに置きます。別の場所に置いたときは、「設定」の「PlutoSDR」でそのフォルダを選びます。
2. PlutoSDR を USB で繋ぐと、機器の一覧に出ます（`ip:192.168.2.1` で探します。変えるときは「設定」の「PlutoSDR」の URI で）。

SG・TG・S11 の出力の強さは、「信号源」タブの「送信の減衰」で決めます。レベルは「dB（未校正）」です。

## GS5.exe の校正ファイルを使う

GS5.exe で使っていた校正ファイル（`gigast.txt` や、機器ごとの個別補正データ）は、メニューの「校正 → 旧校正ファイルを読み込む…」で取り込めます。取り込む先は、いま繋いでいる GigaSt です。

GS5.exe の設定ファイルと保存ファイルは読めません。

## うまくいかないとき

| こうなる | 確かめること |
| --- | --- |
| 機器の一覧に GigaSt が出ない | USB ケーブル（給電だけのケーブルではないか）と FTDI のドライバ。それでも出ないときは「設定」の「接続」の「COM 番号で繋ぐ（GigaSt）」で COM 番号を入れます |
| 「ほかのアプリケーションが使っています」と出る | GS5.exe など、同じ COM ポートを使うアプリを閉じてから［接続］を押します |
| 「DLL が見つかりません」と出る | RTL-SDR・PlutoSDR の DLL の場所と、64 ビット版かどうか |
| TG・S11 で比ではなく dBm が出る | 基準がいまの RBW・イメージ除去と合っていません。基準を取り直します |
| 使えない項目が灰色になっている | 灰色の項目にマウスを置くと、使えない理由が出ます |

## 設定とデータの置き場所

設定・覚えた機器・校正・基準・プリセットは、Windows では `%APPDATA%\NamiBench`、Linux・macOS では `~/.namibench` にあります。
